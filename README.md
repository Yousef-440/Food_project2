# 🍽️ Restaurant Website – Responsive Web Page

A modern and responsive **restaurant landing page** created using **HTML** and **CSS**.  
This website showcases the restaurant’s menu, chefs, and customer testimonials in a clean and appealing design.

## 📄 Features

- 📋 **Menu Section** – Displays a list of food and drinks
- 👨‍🍳 **Our Chefs** – Highlights the professional chefs working in the restaurant
- 💬 **Customer Reviews** – Shows what people are saying about the food and service
- 📱 **Responsive Design** – Works smoothly on all screen sizes (desktop, tablet, mobile)
- 🎨 Visually clean layout and user-friendly navigation
